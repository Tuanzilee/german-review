# 德文複習（german-review）

輔大 115-1「外國語文（基礎德文）」自用複習 PWA。課本：《Schritte International Neu A1.1》，本學期 Lektion 1–3。

## 功能
- 🃏 **單字卡＋間隔重複**：德→中／中→德，翻面自動發音；忘了／模糊／記得 → Leitner 5 盒（1/2/4/7/14 天）
- 💬 **會話跟讀**：逐句播放；可選扮演角色，輪到自己會停下等你說，再播標準答案；可遮住德文、切慢速
- 🎧 **聽力辨識**：只聽德文選中文意思，10 題一輪
- 📕 **錯題本**：單字卡按「忘了」或聽力答錯的會集中在這裡
- 🔊 發音使用裝置內建德語語音（iPhone 建議下載「Anna」：設定 → 輔助使用 → 朗讀內容 → 聲音 → 德文）

進度存在瀏覽器 localStorage，換裝置不會同步。

## 本機預覽
```
python3 -m http.server 8000
```
打開 http://localhost:8000

## 內容來源
- 課堂 Plaud 錄音（老師實際教的單字、句型、變位）
- 課本 Lektion 對應頁（校正拼字、冠詞、複數）
- 會話是依課堂情境**自行改寫**的短對話，不收錄課本原文、掃描圖或音檔
